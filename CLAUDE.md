# Diego y Yo

Proyecto de venta de repuestos. App o web para gestionar y vender repuestos.

## Reglas de modelo

- **Sonnet** → desarrollo, implementación, código (modelo por defecto)
- **Haiku** → búsquedas en el código, leer archivos, preguntas rápidas (`/model haiku`)
- **Opus** → solo para decisiones de arquitectura complejas o problemas difíciles (`/model opus`)

## Contexto

- Negocio de venta de repuestos
- Stack por definir
- Probable necesidad de catálogo de productos, carrito, gestión de inventario
